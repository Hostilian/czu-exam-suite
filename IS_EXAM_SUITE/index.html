Data Warehousing & Business Intelligence SINV · OLAP · ETL · BI Tools
▶
A Data Warehouse is a subject-oriented, integrated, non-volatile, time-variant database optimized for strategic analysis and decision support — NOT for daily transactions.
  • SINV acronym: Subject-oriented, Integrated, Non-volatile, Variant-time
  • OLTP (Online Transaction Processing) = TPS = daily operations
  • OLAP (Online Analytical Processing) = Data Warehouse = strategic analysis
  • Non-volatile: data is stable and never deleted — historical records are permanent
  • Time-variant: stores snapshots of data over time, tracks changes historically
  • BI (Business Intelligence): technologies to analyze data and gain business insights
SINVOLAPOLTP Non-volatileTime-variant ETLData MartBI Dashboard
A Data Warehouse CANNOT be used for daily transactions (OLTP). If the exam asks about "routine operations" — that's TPS. If it asks "strategic analysis" — that's Data Warehouse.
Enterprise Resource Planning (ERP & SAP) SAP Modules · HANA · Vendor Lock-in · P2P
▶
ERP (Enterprise Resource Planning) is an integrated software system managing core business functions across all departments through a single centralized database.
  • IS is MORE GENERAL than ERP — ERP is a specific type of IS
  • Main goal: support decision-making by centralizing and standardizing data
  • Advantage: eliminates data silos, real-time cross-department visibility
  • Disadvantage: very high cost + vendor lock-in risk
  • Leading vendors: SAP, Oracle, Microsoft
  • SAP HANA: next-gen ERP using in-memory database (processes data in RAM)
  • SAP Modules: FI (Finance), CO (Controlling), MM (Materials), SD (Sales), HR, PP
ERPSAP HANA In-memory DBVendor Lock-in FI · CO · MMSD · HR · PP
Know the SAP P2P flow: PR → PO → GR → Invoice (MIRO) → Payment (F110). Each step has a T-code. "MIGO" = goods receipt. "MIRO" = invoice verification.
Decision Support Systems (DSS) Structured · Semi-structured · Unstructured Decisions
▶
A DSS (Decision Support System) is an interactive computer-based system that supports managers by transforming raw data into useful information for strategic decision-making.
  • DSS transforms: raw data → useful information for decisions
  • DSS SUPPORTS, never REPLACES managers — human judgment is essential
  • Structured decision: procedure CAN be fully specified in advance (e.g. payroll)
  • Unstructured decision: procedure CANNOT be specified — needs human intuition (e.g. strategy)
  • Semi-structured: some procedures specified, some human judgment needed
  • Computers: fast at data processing; Humans: flexible, contextual judgment
DSSStructured UnstructuredSemi-structured TPS → OperationalDSS → Tactical/Strategic
"Payroll calculation" = structured (routine, automated). "New market entry decision" = unstructured (needs human judgment). DSS SUPPORTS but does NOT replace managers.
Business Intelligence, KPIs & AI BI · BPM · ML · NLP · Deep Learning · Computer Vision
▶
BI (Business Intelligence) encompasses technologies and practices for analyzing data to create actionable business insights. BPM = BI + Planning. AI extends BI with autonomous learning capabilities.
  • BI: analyze data → create business insights
  • BPM = BI + Planning: uses KPIs to monitor and improve performance
  • KPI: Key Performance Indicator — measurable value showing goal achievement
  • 4 AI areas on exam: NLP, Machine Learning, Computer Vision, Deep Learning
  • Machine Learning: learns patterns from data without explicit programming
  • Deep Learning: multi-layer neural networks (inspired by human brain)
  • NLP: processing/understanding human language (text, speech)
  • Computer Vision: enabling machines to interpret visual/image data
BIBPM = BI + Planning KPIML NLPDeep LearningComputer Vision
BPM formula: BI + Planning = BPM. Modern IS phenomena (exam question): cloud computing, virtualization, big data, AI, security.
Cloud Computing SaaS · PaaS · IaaS · On-demand · SOA
▶
Cloud Computing is the on-demand provision of IT services via the internet on a pay-per-use model, enabling scalable and flexible resource access without owning physical hardware.
  • Core idea: pay for what you use — scalable, on-demand
  • SaaS = Software as a Service (e.g. Gmail, Office 365, Salesforce)
  • PaaS = Platform as a Service = IaaS + OS + App Platform (e.g. Heroku)
  • IaaS = Infrastructure as a Service — servers, storage, networking (e.g. AWS EC2)
  • Architecture evolution: toward SOA (Service-Oriented Architecture) / API-based
SaaSPaaS IaaSOn-demand SOAPay-per-use
Stack order: IaaS (lowest, hardware) → PaaS (IaaS + OS + Platform) → SaaS (highest, full application). Gmail = SaaS. AWS EC2 = IaaS. Heroku = PaaS.
Information Security CIA Triad · ACID · SAP Authorization · Backup Types
▶
Information security protects data through Confidentiality, Integrity, and Availability (CIA Triad). Database consistency is maintained through ACID properties. SAP uses hierarchical authorization.
  • CIA Triad: Confidentiality, Integrity, Availability
  • ACID: Atomicity, Consistency, Isolation, Durability
  • Atomicity: transaction is all-or-nothing (bank transfer either completes or doesn't)
  • SAP Authorization hierarchy: User → Roles → Profiles → Authorization Objects
  • Differential backup: saves changes since last FULL backup
  • Incremental backup: saves changes since last backup of ANY type
  • Social Engineering: manipulating people (not systems) — e.g. Pretexting, Phishing
CIA TriadACID AtomicityAvailability DifferentialIncremental Social Engineering
The A in CIA = Availability (not Authentication!). Differential = since last FULL. Incremental = since last ANY backup. SAP hierarchy: User → Role → Profile → Auth Object.
IS Basics & Competitive Intelligence IS vs ERP · Management Interaction · CI Sources
▶
Information Systems interact with management — IS supports managers, managers set IS parameters. Competitive Intelligence (CI) uses legal/public sources to understand competitive environment.
  • IS and management interact: IS supports; managers set parameters/rules
  • Goal of IS: support management — NEVER replace decision makers
  • IS is MORE GENERAL than ERP — ERP is a specific type of IS
  • CI (Competitive Intelligence): legal, ethical gathering from public sources only
  • CI is NOT espionage: uses press releases, news, government records, public databases
  • CI purpose: improve understanding of competitive environment for strategic decisions
IS ⊃ ERPManagement Interaction CIPublic Sources Legal & Ethical
CI uses only LEGAL public sources — press releases, news, databases. Never hacking or espionage. Automatic stock ordering = IS tool (triggers when inventory falls below threshold set by humans).
