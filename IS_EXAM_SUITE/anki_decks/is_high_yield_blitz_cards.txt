What are the 4 IS levels (pyramid)?	<b>TPS</b> (Operational) → <b>MIS</b> (Managerial) → <b>DSS</b> (Tactical/Strategic) → <b>EIS/ESS</b> (Executive)<br><span class="fg">TPS</span> = daily transactions · <span class="fb">MIS</span> = management reports · <span class="fa">DSS</span> = decisions · <b>EIS</b> = executive dashboards	blitz_is_theory
What is a Decision Support System (DSS)?	An <b>interactive computer-based system</b> that supports decision-making. Transforms <span class="fa">raw data → useful information</span>. Supports STRATEGIC and TACTICAL decisions. Should <b>SUPPORT managers, NOT replace them</b>.	blitz_is_theory
What are the 3 decision types?	<b style="color:#4ade80">Structured:</b> Procedure CAN be specified in advance (payroll, reorder)<br><b style="color:#f87171">Unstructured:</b> Procedure CANNOT be specified (CEO strategy, hiring)<br><b style="color:#f59e0b">Semi-structured:</b> SOME procedures specifiable, but not enough for definite decision	blitz_is_theory
IS vs ERP — which is more general?	<b>IS (Information Systems)</b> is MORE GENERAL. ERP is a specific TYPE of IS. Every ERP is an IS, but NOT every IS is an ERP.	blitz_is_theory
What is BI and BPM?	<b>BI (Business Intelligence):</b> Analyzes data to create business insight<br><b>BPM (Business Performance Management):</b> <span class="fa">BI + Planning</span><br><b>KPI:</b> Key Performance Indicator — measurable value of goal achievement<br><b>Dashboard:</b> Visual display of important business KPIs	blitz_is_theory
What is Competitive Intelligence (CI)?	<b>Legal and ethical</b> gathering of information about competitors. Uses PUBLIC sources only (press releases, reports, news). Goal: improve understanding of competitive environment. CI ≠ espionage!	blitz_is_theory
What are SDLC phases?	<b>Planning</b> → <b>Analysis</b> → <b>Design</b> → <b>Implementation</b> → <b>Maintenance</b><br>Waterfall: sequential. Agile: iterative sprints (2-4 weeks).<br>SCRUM roles: Product Owner · Scrum Master · Development Team	blitz_is_theory
What is BPR?	<b>Business Process Reengineering</b> — Radical redesign of business processes to achieve dramatic improvements in performance, cost, quality, and speed. Not incremental improvement — RADICAL redesign!	blitz_is_theory
What are IS rules set by?	Rules in IS are set by <b>humans (managers)</b> through parameters and settings. The system does NOT set its own rules. Goal of IS = SUPPORT management, not replace it.	blitz_is_theory
What is an automatic tool example in IS?	<b>Automatic stock reordering</b> — when inventory drops below a set level, the system automatically generates a purchase order. The HUMAN sets the threshold; the IS executes automatically.	blitz_is_theory
What are the 4 DW characteristics (SINV)?	<b>S — Subject-Oriented:</b> Organized around subjects (sales, products)<br><b>I — Integrated:</b> Combines data from multiple sources consistently<br><b>N — Non-Volatile:</b> Data is stable/historical, NOT updated like OLTP<br><b>V — Time-Variant:</b> Every record has timestamp; tracks historical changes	blitz_data_warehouse
What is Non-Volatile in a Data Warehouse?	Data in a DW is <b>stable and historical</b> — it is NOT deleted or changed like operational OLTP data. Once loaded, DW data is permanent. This is different from TPS/OLTP where data changes constantly.	blitz_data_warehouse
What is Time-Variant in a Data Warehouse?	DW data is <b>connected with time</b> — every record has a timestamp or time period. The DW tracks HISTORICAL changes over time (e.g., sales trends over 5 years), unlike OLTP which only stores current state.	blitz_data_warehouse
TPS vs Data Warehouse — what is each for?	<b>TPS (Transaction Processing System):</b> Daily operational transactions (current data, OLTP)<br><b>Data Warehouse:</b> <span class="fa">Strategic analysis</span> and decision-making (historical data, OLAP)	blitz_data_warehouse
What is ETL?	<b>Extract</b> — pull data from source systems (ERP, CRM, CSV)<br><b>Transform</b> — clean, standardize, aggregate, fix formats<br><b>Load</b> — write transformed data into the Data Warehouse	blitz_data_warehouse
Star Schema vs Snowflake Schema?	<b>Star Schema:</b> Central fact table + surrounding dimension tables. Denormalized, fast queries, simple.<br><b>Snowflake Schema:</b> Fact + dimension + sub-dimension tables. Normalized, saves space, more complex queries.	blitz_data_warehouse
What is OLTP vs OLAP?	<b>OLTP</b> (Online Transaction Processing): operational, INSERT/UPDATE/DELETE, real-time, high volume, TPS<br><b>OLAP</b> (Online Analytical Processing): analytical, SELECT/aggregate, historical, DW/BI tools, reports	blitz_data_warehouse
What is a Data Mart?	A <b>subset of a Data Warehouse</b> focused on one specific department or business area. E.g., a Sales Data Mart contains only sales-related data from the larger DW.	blitz_data_warehouse
Big Data 3Vs?	<b>Volume</b> — huge amount of data<br><b>Velocity</b> — data generated and processed at high speed<br><b>Variety</b> — structured, unstructured, semi-structured data types	blitz_data_warehouse
What is ERP?	<b>Enterprise Resource Planning</b> — Integrated software managing ALL core business processes (finance, HR, sales, manufacturing) in one system with a shared database. Leaders: <b>SAP, Oracle, Microsoft</b>.	blitz_erp_sap
ERP main advantage vs main disadvantage?	<b>Advantage:</b> Centralized data + real-time visibility across all departments<br><b>Disadvantage:</b> <span class="fa">HIGH COSTS</span> and vendor lock-in (dependency on one vendor, hard to switch)	blitz_erp_sap
SAP Organizational Hierarchy?	<b>Client</b> (top, entire SAP system)<br>→ <b>Company Code</b> (legal entity)<br>→ → <b>Plant</b> (production/service location)<br>→ → → <b>Storage Location</b> (physical storage within plant)	blitz_erp_sap
What are the 6 main SAP modules?	<b>FI</b> — Financial Accounting (general ledger, reporting)<br><b>CO</b> — Controlling (cost centers, internal reporting)<br><b>MM</b> — Materials Management (procurement, inventory)<br><b>SD</b> — Sales & Distribution (order-to-cash)<br><b>HR/HCM</b> — Human Resources (payroll)<br><b>PP</b> — Production Planning (manufacturing)	blitz_erp_sap
P2P T-code sequence?	<b>ME51N</b> (Purchase Requisition)<br>→ <b>ME21N</b> (Purchase Order)<br>→ <b>MIGO</b> (Goods Receipt)<br>→ <b>MIRO</b> (Invoice Verification — 3-way match)<br>→ <b>F110</b> (Automatic Payment)	blitz_erp_sap
O2C T-code sequence?	<b>VA01</b> (Sales Order — customer places order)<br>→ <b>VL01N</b> (Delivery — ship goods)<br>→ <b>VF01</b> (Billing — create customer invoice)	blitz_erp_sap
What is SAP HANA?	<b>High-performance Analytic Appliance</b> — an <span class="fg">in-memory database</span>. All data stored in RAM (not disk). Enables real-time analytics. 1000× faster than disk-based databases. S/4HANA is the next-gen ERP built exclusively on SAP HANA.	blitz_erp_sap
Master Data vs Transactional Data in SAP?	<b>Master Data:</b> Permanent data used repeatedly — customers, materials, vendors (rarely changes)<br><b>Transactional Data:</b> Created for each transaction — purchase orders, invoices, sales orders (changes constantly)	blitz_erp_sap
SaaS vs PaaS vs IaaS — who manages what?	<b>IaaS:</b> Provider manages hardware/network. You manage OS + middleware + apps. (AWS EC2, Azure VMs)<br><b>PaaS:</b> IaaS + OS + App Platform managed. You manage code only. (Heroku, GAE)<br><b>SaaS:</b> Provider manages everything. You just use the app. (Gmail, Salesforce)	blitz_cloud_architecture
PaaS = ?	PaaS = <b>IaaS + OS + Application Platform (runtime)</b>. You manage only the application code. Provider manages everything below (hardware, network, OS, runtime environment).	blitz_cloud_architecture
Cloud computing core concept?	Provision of IT services via the internet. Core idea: <b>"pay for what you use"</b> — on-demand, elastic, measured service. Three service models: IaaS, PaaS, SaaS.	blitz_cloud_architecture
GDPR data — which cloud?	GDPR-sensitive data (personal data of EU citizens) should stay in a <b>private cloud</b> to maintain control and compliance. Public cloud for general web applications.	blitz_cloud_architecture
SOA vs Microservices?	<b>SOA (Service-Oriented Architecture):</b> Large services communicating via enterprise service bus (ESB). More tightly coupled.<br><b>Microservices:</b> Small independent services communicating via REST APIs. Loosely coupled, independently deployable.	blitz_cloud_architecture
Three-tier architecture?	<b>Presentation tier</b> (UI — browser/client)<br><b>Application/Logic tier</b> (business logic — web server)<br><b>Data tier</b> (database)<br>Separates concerns for scalability and maintainability.	blitz_cloud_architecture
CIA Triad?	<b>C — Confidentiality:</b> Only authorized users can access data (encryption, passwords, MFA)<br><b>I — Integrity:</b> Data is accurate and untampered (checksums, digital signatures)<br><b>A — Availability:</b> Systems accessible when needed (backups, redundancy, uptime)	blitz_security
ACID database properties?	<b>A — Atomicity:</b> All or nothing (full commit or full rollback)<br><b>C — Consistency:</b> DB moves from one valid state to another<br><b>I — Isolation:</b> Concurrent transactions don\	blitz_security
Authentication vs Authorization?	<b>Authentication:</b> Verifying WHO you are (identity) — username + password, biometrics<br><b>Authorization:</b> Verifying WHAT you can do (permissions) — roles, access rights<br>Authentication ALWAYS happens before authorization.	blitz_security
Symmetric vs Asymmetric Encryption?	<b>Symmetric:</b> Same key for encrypt and decrypt. Fast. Problem: how to share the key securely? Examples: AES, DES<br><b>Asymmetric:</b> Public key (encrypt) + Private key (decrypt). Solves key exchange. Examples: RSA, used in TLS/HTTPS	blitz_security
3 backup types?	<b>Full:</b> Complete copy of everything. Slow to create, fast to restore.<br><b>Incremental:</b> Changes since last backup (any type). Fast to create, slow to restore.<br><b>Differential:</b> Changes since last FULL backup. Medium speed both ways.	blitz_security
4 areas of AI?	<b>NLP (Natural Language Processing):</b> Human language understanding<br><b>Machine Learning:</b> Learning patterns from data<br><b>Computer Vision:</b> Interpreting visual/image data<br><b>Deep Learning:</b> Multi-layer neural networks (subset of ML)	blitz_ai_modern_tech
Deep Learning vs Machine Learning?	<b>Machine Learning:</b> Algorithms learn from data. Feature engineering by humans.<br><b>Deep Learning:</b> Subset of ML using <span class="fg">multi-layer neural networks</span>. Automatic feature extraction. Inspired by human brain structure. Needs more data and compute.	blitz_ai_modern_tech
Modern IS technologies?	<b>Cloud computing</b> (scalable, on-demand)<br><b>Virtualization</b> (virtual machines)<br><b>Big Data</b> (volume, velocity, variety)<br><b>AI</b> (ML, NLP, Computer Vision)<br><b>Security</b> (CIA, encryption, GDPR)	blitz_ai_modern_tech
Application architecture evolved toward?	<b>Service-Oriented Architecture (SOA)</b> and then <b>Microservices</b> + <b>REST APIs</b>. Moving from monolithic applications to independently deployable small services.	blitz_ai_modern_tech
