## 📚 Topic Coverage

### 1. IS Theory
- Types of IS: **TPS → MIS → DSS → EIS/ESS** (4 levels pyramid)
- Data vs Information vs Knowledge
- SDLC phases: Planning → Analysis → Design → Implementation → Maintenance
- Agile vs Waterfall, SCRUM roles (Product Owner, Scrum Master, Dev Team)
- BPR (Business Process Reengineering)

### 2. Databases in IS
- **OLTP vs OLAP** (real-time transactions vs analytical queries)
- Data Warehouse: ETL, Star Schema, Snowflake Schema
- Data Marts, Data Mining techniques
- **ACID** properties (Atomicity, Consistency, Isolation, Durability)
- NoSQL vs SQL for IS

### 3. ERP Systems & SAP Basics
- SAP **organizational levels**: Client > Company Code > Plant > Storage Location
- SAP **modules**: FI, CO, MM, SD, HR/HCM, PP
- Master Data vs Transactional Data
- SAP GUI navigation & **T-codes**
- **SAP HANA** (in-memory DB) vs R/3

### 4. Business Processes in SAP
- **Procure-to-Pay (P2P)**: ME51N → ME21N → MIGO → MIRO → F110
- **Order-to-Cash (O2C)**: VA01 → VL01N → VF01
- Record-to-Report (R2R) in FI/CO

### 5. IS Security
- **CIA Triad**: Confidentiality, Integrity, Availability
- Authentication vs Authorization
- Multi-Factor Authentication (MFA)
- SAP Authorization concept: User → Role → Profile → Auth Objects
- Encryption (symmetric/asymmetric), SQL Injection, GDPR
- Backup strategies: Full / Incremental / Differential

### 6. Cloud & Architecture
- **SaaS / PaaS / IaaS** (with examples and who manages what)
- SOA (Service-Oriented Architecture) vs Microservices
- REST API, Three-tier architecture
- On-premises vs Cloud (CAPEX vs OPEX)
- Digital Transformation

### 7. Project Management
- Waterfall vs Agile
- SCRUM roles and sprints
- IS project phases
