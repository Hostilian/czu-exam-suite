## 📱 Mobile Study (Anki)

1. Open Anki on your phone
2. Import `anki_decks/orsa_exam_cards_v4.txt` for the **Normal** deck
3. Import `anki_decks/orsa_exam_cards_v4_cram.txt` for the **Cram** deck
4. Set card separator to `Tab` and field separator to `|` if prompted
