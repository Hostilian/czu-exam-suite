Input-Output Analysis (Leontief)
ALWAYS on exam. Nobel Prize 1973. Use Excel: MINVERSE + MMULT.
⚠
Exam Pattern: You WILL get a partially blank I-O table to complete, then build A matrix, then calculate new outputs from changed final demand. Know this process cold.

Key Concepts

  • Transaction Matrix Z — z_ij = value flowing FROM sector i TO sector j
  • Total Output X_i — sum of all sales by sector i (use row sum)
  • Final Demand y_i — sales to households, govt, export
  • Primary Inputs — Wages, EBIT, Materials (column residual)
  • Technical Coeff a_ij = z_ij / X_j (divide by COLUMN total!)
  • Leontief Inverse M = (I-A)^-1 — multiplier matrix

3 Golden Balancing Rules

Rule 1 (ROW): X_i = sum(z_ij) + y_i Total output = row sum + final demand Rule 2 (COL): X_j = sum(z_ij) + primary_inputs Total input = col sum + wages + EBIT Rule 3 (IDENTITY): X_row = X_col same sector Total output = Total input always!

Step-by-Step Algorithm (Do in this exact order!)

1
Complete the table — Use ROW balance first (easier). Find rows with exactly one unknown. Then use COLUMN balance for primary inputs (wages, EBIT).
2
Build A matrix — a_ij = z_ij / X_j. Divide EACH cell by its COLUMN's total output X_j. NOT the row total. This is the #1 mistake.
3
Build (I-A) matrix — Subtract A from Identity matrix. Identity has 1s on diagonal, 0s elsewhere.
4
Given NEW X (total outputs): Find new y = (I-A) * new_x_vector
5
Given NEW Y (final demand): Find new x = (I-A)^-1 * new_y_vector — In Excel: =MMULT(MINVERSE(I_minus_A), y_vector)
EXCEL FORMULAS: Inverse: Select NxN empty area, type =MINVERSE(I_minus_A_range), press Ctrl+Shift+Enter New x: Select Nx1 empty area, type =MMULT(inverse_range, y_column), press Ctrl+Shift+Enter A matrix: In cell = z_ij / X_j (example: =B3/B$6 where row 6 is totals — lock row with $)
💡
Price Index (if asked): Ip = MMULT(MINVERSE(I-Transpose(A)), MMULT(diag_X_inverse, SumVector)). SumVector = W*Iw + M*Im + E*Ie where each I is price index vector.

Linear Programming and Sensitivity Analysis
Excel Solver setup + interpreting sensitivity report. Very high exam weight.
🚨
CRITICAL: ALL LHS cells MUST use =SUMPRODUCT() formulas. Never hardcode values. The teacher checks formulas during grading. This alone can cost you many points.

LP Problem Structure

  • Objective Function: max/min Z = c1*x1 + c2*x2 + c3*x3
  • Constraints: resource limits (le), minimum requirements (ge), equalities
  • Non-negativity: x1, x2 ge 0 always!
  • Optimal solution is ALWAYS at a vertex (corner point)
  • Slack = unused resource in le constraint (= 0 when binding)
  • Surplus = excess over minimum in ge constraint

Excel Solver Required Setup

  • Objective Cell: =SUMPRODUCT(x_cells, c_cells) — Set to Maximize
  • By Changing Variable Cells: select x1, x2, x3 cells
  • Constraints: add each (LHS formula cell le/ge/= RHS value cell)
  • Solving Method: Simplex LP
  • Check: Make Unconstrained Variables Non-Negative
  • After: go to Reports tab, select Sensitivity

Markov Chains
Transition matrices, state vectors, step-by-step vector multiplication

Core Definitions

  • Markov Chain: system moving between states stochastically
  • Markov Property (memoryless): next state depends ONLY on current state, not history
  • Transition Matrix P: P_ij = probability of going FROM state i TO state j
  • ROW sums must = 1 (always, no exceptions, verify each row!)
  • State vector pi(t): probability distribution at time t
  • Absorbing state: P_ii = 1, once entered, never leave
  • Irreducible chain: can reach any state from any other state
  • Stationary distribution: pi* such that pi* * P = pi*

Calculation Formulas

Move one step forward: pi(t) = pi(t-1) * P (row vector times matrix) Multi-step calculation: pi(t) = pi(0) * P^t Specific trajectory probability: P(A to B to C) = P(X0=A) * P_AB * P_BC Stationary distribution: Solve: pi* * P = pi* AND sum(pi*_i) = 1 Replace last equation with sum=1

How to Calculate Step by Step (Exam Method)

Given: pi(0) = [0.5, 0.3, 0.2] P = [ [0.7, 0.2, 0.1], [0.3, 0.5, 0.2], [0.1, 0.3, 0.6] ] STEP 1 — Calculate pi(1) = pi(0) * P: pi(1)_A = pi(0)_A * P_AA + pi(0)_B * P_BA + pi(0)_C * P_CA = 0.5*0.7 + 0.3*0.3 + 0.2*0.1 = 0.35+0.09+0.02 = 0.46 pi(1)_B = 0.5*0.2 + 0.3*0.5 + 0.2*0.3 = 0.10+0.15+0.06 = 0.31 pi(1)_C = 0.5*0.1 + 0.3*0.2 + 0.2*0.6 = 0.05+0.06+0.12 = 0.23 VERIFY: 0.46+0.31+0.23 = 1.0 ALWAYS CHECK THIS! STEP 2 — Repeat with pi(1) as new starting vector for pi(2).
🚨
Row sums of transition matrix P must ALWAYS be exactly 1.0. After each step calculation, verify your state vector sums to 1.0. If not, you made an arithmetic error.

Queuing Theory — M/M/1 Queue
Single server, Poisson arrivals, exponential service. Know all 6 formulas.

All 6 M/M/1 Formulas — These Are the ONLY Ones You Need

Given: lambda = arrival rate per hour, mu = service rate per hour rho = lambda / mu Server utilization (MUST be less than 1 for stability!) P0 = 1 - rho Probability server is IDLE (= prob customer does NOT wait) Lq = rho^2 / (1 - rho) Average customers IN QUEUE (waiting, not being served) L = rho / (1 - rho) Average customers IN SYSTEM (queue + being served) Wq = Lq / lambda Average time customer WAITS IN QUEUE (in hours) W = 1 / (mu - lambda) Average total time IN SYSTEM = Wq + 1/mu To convert hours to minutes: multiply by 60 If given time (minutes) for service, convert to rate: mu = 60/service_time_minutes

System Dynamics and Causal Loop Diagrams
Link signs, loop polarity rules, and the 8 archetypes

Causal Link Signs

Positive link (+) or S (Same): A ---(+)--- B If A increases, B increases. If A decreases, B decreases. Example: Population ---(+)--- Births Negative link (-) or O (Opposite): A ---(-)--- B If A increases, B decreases. If A decreases, B increases. Example: Inventory ---(-)----- Order Rate Delay = double line || drawn across the arrow

Loop Polarity — THE RULE

Count NEGATIVE (O or -) links in the closed loop: EVEN count (0, 2, 4...): REINFORCING loop (R or +) Amplifies change — exponential growth or collapse ODD count (1, 3, 5...): BALANCING loop (B or -) Seeks equilibrium — goal-seeking, stabilizing Mnemonic: Even = Exponential, Odd = Opposes

Systems Thinking and Soft Systems Methodology (SSM)
Theory questions, definitions, CATWOE, 7 stages of SSM

Key Definitions to Memorize

  • System: group of elements + relations; maintains existence through mutual interaction; more than sum of parts
  • Closed System: does NOT need environment (atoms, molecules)
  • Open System: MUST interact with environment (people, organizations)
  • Complex System: behavior of whole cannot be explained by parts alone
  • 5 Complex System Properties: Self-organization, Emergence, Nonlinearity, Adaptation, Feedback loops
  • Model: simplified version of reality for understanding/analysis; cheaper, reproducible
  • Normative model: what SHOULD be done (evaluates best action)
  • Descriptive model: what IS being done (no judgment)

CATWOE — SSM Root Definition Analysis Tool

C = Customers / Beneficiaries / Victims (who is affected by the transformation) A = Actors (who PERFORMS the transformation — does the work) T = Transformation (core process: Input ---> Output) W = Weltanschauung / Worldview (belief that makes transformation MEANINGFUL — WHY?) O = Owners (who can START, CHANGE, or STOP the system) E = Environment (external constraints the system must accept as given) Root Definition template: "A system to do X (T), by Y (A), in order to achieve Z (W)" SSM developer: Peter Checkland, University of Lancaster, UK, late 1960s

Vensim SFD — Critical Rules and Equations
Point deduction rules. Each violation costs 5-10 points.

RULE 1 — (-10 pts)

NEVER connect Stock to Stock directly with a causal arrow.

Stocks exchange substance ONLY via Flow pipes. Causal (information) arrows from stocks go only to flows or auxiliaries, never directly to another stock.

RULE 2 — (-5 pts)

All causal arrows MUST have correct polarity signs (+/S or -/O).

If A increases and causes B to increase: use + or S (Same).
If A increases and causes B to decrease: use - or O (Opposite).

RULE 3 — (-6/-4 pts)

Identify and name all feedback loops.

Use Vensim Loop Utility. Label each loop as R1, R2... (Reinforcing) or B1, B2... (Balancing). Place label inside the loop.

SIR Epidemic Model — Key Equations (Common Exam Template)

Stocks: Susceptible population = INTEG(recovery without immunity - infection rate, 49990) Infected population = INTEG(infection rate - recovery with immunity - recovery without immunity - death rate, 10) Immune population = INTEG(recovery with immunity, 0) Total deaths = INTEG(death rate, 0) Key Flows and Auxiliaries: infection rate = total contacts * share of infected * INFECTIVITY total contacts = Susceptible * AVERAGE NUMBER OF RISK CONTACTS share of infected = Infected / (Infected + Susceptible + Immune) exit rate = Infected / AVERAGE DURATION OF INFECTION recovery rate = exit rate * (1 - MORTALITY) recovery with immunity = recovery rate * SHARE OF IMMUNE recovery without immunity = recovery rate * (1 - SHARE OF IMMUNE) death rate = exit rate * MORTALITY Constants (typical values): AVERAGE NUMBER OF RISK CONTACTS = 10 AVERAGE DURATION OF INFECTION = 7 (days) INFECTIVITY = 0.05 SHARE OF IMMUNE = 0.5 MORTALITY = 0.03

You have Excel during the exam. Use it for everything.

Essential Excel Functions

Matrix Operations (ARRAY formulas — Ctrl+Shift+Enter): =MINVERSE(A1:C3) Matrix inverse of 3x3 =MMULT(A1:C3, E1:E3) Matrix * column vector =TRANSPOSE(A1:C3) Transpose matrix LP Solver: =SUMPRODUCT(x_range, coeff_range) LHS and objective Markov (step calculations): =MMULT(pi_vector, P_matrix) One step =MMULT(MMULT(pi,P),P) Two steps Statistics: =BINOM.DIST(k, n, p, FALSE) P(X=k) binomial =FACT(n)/(FACT(k)*FACT(n-k)) Combination C(n,k) =POISSON.DIST(k, lambda, FALSE) P(X=k) Poisson

M/M/1 Quick Setup in Excel

Cell A1: lambda = 24 (arrivals per hour) Cell A2: mu = 30 (service per hour) Cell A3: rho = =A1/A2 Cell A4: P0 = =1-A3 Cell A5: Lq = =A3^2/(1-A3) Cell A6: L = =A3/(1-A3) Cell A7: Wq = =A5/A1 (hours) Cell A8: Wq_m = =A7*60 (minutes) Cell A9: W = =1/(A2-A1) (hours) Cell A10: W_m = =A9*60 (minutes)

I-O Analysis in Excel — Complete Walkthrough

STEP 1: Enter Z matrix (transactions) in cells, e.g., B2:D4 STEP 2: Enter X_j totals in a row, e.g., B5:D5 (column totals) STEP 3: A matrix — in new area, each cell: =B2/B$5 (B$5 locks row 5 — dollar before row number) STEP 4: Identity I — manually: 1s on diagonal, 0s off-diagonal STEP 5: (I-A) matrix — for each cell: =I_cell - A_cell STEP 6: Leontief Inverse — select empty 3x3, type: =MINVERSE(I_minus_A_range), then Ctrl+Shift+Enter STEP 7: New x = Inverse * y_new: Select empty 3x1 column, type: =MMULT(inverse_3x3, y_new_column), then Ctrl+Shift+Enter IMPORTANT: After pressing Ctrl+Shift+Enter you will see curly braces { } around the formula This means it is correctly entered as an array formula.
