Question 3: Linear Programming Sensitivity 4 Points
For a linear programming maximization problem, a binding resource constraint has a right-hand side (RHS) of 200, a shadow price of 15, and an allowable increase of 50. If the RHS of this constraint is increased to 230, what happens to the total optimal profit (Z)?
A The optimal profit increases by exactly 450 units.
B The optimal profit increases by exactly 300 units.
C The optimal profit remains unchanged because the basis does not change.
D The problem becomes infeasible because the increase is outside the allowable range.

Correct Option: A

Explanation:
1. Calculate the change in the RHS: \(\Delta ext{RHS} = 230 - 200 = +30\).
2. Verify if the change is within the allowable range: \(30 \le ext{Allowable Increase (50)}\). Since it is within the range, the shadow price remains valid.
3. Calculate the change in profit: \(\Delta Z = ext{Shadow Price} imes \Delta ext{RHS} = 15 imes 30 = +450\).
Thus, the profit increases by 450 units.

Question 4: Markov Chain Transition Matrix Properties 4 Points
For a transition probability matrix \(P\) of a discrete-time Markov chain, which of the following properties must always hold true?
A The sum of the probabilities in each column must equal 1.
B The sum of the probabilities in each row must equal 1.
C Every individual probability value in the matrix must be strictly greater than 0.
D The transition probabilities must be non-stationary (changing over time).

Correct Option: B

Explanation:
A transition matrix represents the probabilities of moving from a state (represented by the row) to any other state (represented by the columns). Since the system must transition to *some* state (even if it stays in the same state), the sum of all transition probabilities from any given state must equal 1. Therefore, each row sums to 1. Columns do not need to sum to 1.

Question 5: System Dynamics Loop Polarity 4 Points
In System Dynamics, a causal loop diagram contains a feedback loop: Births \( ightarrow\) Population \( ightarrow\) Births. There are no negative links in this loop. This loop is classified as a:
A Balancing (B) loop, because it maintains the population at a steady carrying capacity.
B Reinforcing (R) loop, because it leads to exponential growth or decay.
C Goal-seeking loop, because it drives the system toward a target value.
D Negative feedback loop, because births consume system resources.

Correct Option: B

Explanation:
The polarity of a feedback loop depends on the number of negative relationship links. If the number of negative links is even (including zero), the loop is reinforcing (R). Since there are 0 negative links in this loop, it is reinforcing. This results in exponential growth of the population (as more births occur, the population increases, which leads to even more births).

A Work-system — representing the physical infrastructure and resources used to perform the transformation.
B Weltanschauung — representing the underlying worldview or belief system that makes the transformation meaningful.

Question 7: Vensim Diagramming Rules 4 Points
When building a Stock and Flow diagram in Vensim, which of the following diagramming practices is strictly prohibited?
A Drawing a causal arrow from a Stock variable to a Flow variable.
B Connecting two Stock variables directly with a blue causal arrow.
C Drawing a flow pipe from a cloud (infinite source) to a Stock variable.
D Connecting an Auxiliary variable to a Flow variable with a causal arrow.

Correct Option: B

Explanation:
In system dynamics, stocks can only change through flow variables (represented by valves/pipes). You cannot draw a direct causal arrow from Stock A to Stock B. Instead, a Stock can influence the *flow* (valve) that enters or exits another Stock. Causal arrows from Stock to Stock are a major structural error in Vensim.

Correct Answers & Step-by-Step Math:

Part (a) Operating Metrics:
• Utilization: \( ho = \lambda/\mu = 24/30 = \mathbf{0.80}\) (or 80% busy)
