Section B4: Queuing Theory (Q12)

⏱ M/M/1 Complete Solution (λ=24, μ=30)
ρ = λ/μ = 24/30 = 0.80 (80% utilization)
P0 = 1 − ρ = 1 − 0.80 = 0.20 (20% of time server idle)

Lq = ρ²/(1−ρ) = 0.64/0.20 = 3.2 students (avg in queue)
L = ρ/(1−ρ) = 0.80/0.20 = 4.0 students (avg in system)

Wq = Lq/λ = 3.2/24 = 0.1333 hr = 8.0 minutes (avg wait in queue)
W = 1/(μ−λ) = 1/6 hr = 10.0 minutes (avg time in system)

Part (b) — Find μ for Wq ≤ 2 min = 1/30 hr:
Wq = λ/[μ(μ−λ)] ≤ 1/30
24/[μ(μ−24)] ≤ 1/30
720 ≤ μ² − 24μ
μ² − 24μ − 720 = 0
μ = [24 + √(576+2880)]/2 = [24 + 58.79]/2 = ≈ 41.4 students/hour
→ Service time needed: 60/41.4 ≈ 1.45 minutes per student
