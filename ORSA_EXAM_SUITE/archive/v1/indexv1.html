🧩 Systems Science & Systems Thinking

System
A group of elements and their relations. Maintains existence through mutual interaction of parts. More than the sum of its parts.
Closed System
Does NOT need to interact with the environment. Examples: atoms, molecules.
Open System
MUST interact with the environment. Examples: people, organizations.
Complex System — 5 Properties
1. Self-Organization — organizes without external control
2. Emergence — whole behavior cannot be predicted from parts alone
3. Nonlinearity — small changes → disproportionate effects
4. Adaptation — changes behavior in response to environment
5. Feedback Loops — outputs routed back as inputs
Hard vs. Soft Systems Thinking
Hard Optimizes design using defined performance criteria. Powerful quantitative tools, but ignores social/personal dynamics.

Soft Improves conceptual model via SSM. Stays connected to personal aspect; no final optimal answer.
Model Types
Normative vs. Descriptive: What should be vs. what is
Static vs. Dynamic: Point-in-time vs. changes over time
Deterministic vs. Stochastic: Known vs. random/uncertain
Time & Probability
Time: In models, represented as continuous variable or discrete intervals.
Probability: Quantifies likelihood of an event occurring. Range: 0 (impossible) → 1 (certain).

🗺️ Soft Systems Methodology (SSM)

Developed by Peter Checkland (late 1960s, University of Lancaster). For situations with multiple goals, perspectives, different assumptions, high entanglement.

7 Stages of SSM

Stage 1 — Problem Situation (Real World)
Acknowledge and explore the problem area unstructuredly via surveys, interviews, observations.
Stage 2 — Rich Picture (Real World)
Cartoon-like diagram including: Structures, Processes, Climate, People, Issues, Conflicts.
Stage 3 — Root Definitions (Conceptual World)
Structure: "A system to do X, by Y, in order to do Z."

CATWOE — Customers/Beneficiaries/Victims, Actors, Transformation, Weltanschauung, Owners, Environmental Constraints.
Stage 4 — Conceptual Model (Conceptual World)
Logical diagram of ~7±2 activities (verbs in imperative). Must satisfy 9 systems properties (purpose, performance, decision, subsystems, interactions, environment, boundary, resources, continuity).
Stage 5 — Comparison (Real World)
Compare model to reality via matrix: Does it exist? How does it behave? How is it measured?
Stage 6 — Desirable & Feasible Changes
Owner Analysis, Social System Analysis, Political Analysis.
Stage 7 — Action to Improve
Implement changes → may trigger new inquiry cycle.

📈 Linear Programming

Objective Function
Linear expression to maximize (profit) or minimize (cost).
Decision Variables
Unknown quantities (x₁, x₂…) to be solved for.
Constraints
Linear inequalities restricting variables. Always include non-negativity: xᵢ ≥ 0.
Feasible Region
Set of all points satisfying all constraints simultaneously.
Optimal Solution
Always at a corner point (vertex) of the feasible region.
Slack vs. Surplus Variable
Slack: Unused capacity in a ≤ constraint.
Surplus: Excess over minimum in a ≥ constraint.
Shadow Price
Rate of change in objective per 1-unit increase in a resource RHS.
New Profit = Old Profit + (Shadow Price × ΔRHS)
If constraint is NOT binding → Shadow Price = 0.
Sensitivity Analysis
Studying how changes in model parameters (obj. coefficients or RHS values) affect the optimal solution.
⚠️ Excel Solver Rule: LHS cells must contain active =SUMPRODUCT() formulas. Never hardcode LHS values!

🏢 Input-Output Analysis

Wassily Leontief
Nobel Prize 1973. Developed I-O analysis to model relationships between economy sectors.
Technical Coefficient aᵢⱼ
Value of inputs from sector i needed to produce 1 unit in sector j.
aᵢⱼ = zᵢⱼ / Xⱼ
Leontief Matrix (I-A)
I is identity matrix, A is tech coefficient matrix.
Leontief Inverse (I-A)⁻¹
Also called multiplier matrix M. Represents direct + indirect inputs needed to satisfy 1 unit of final demand.
Key Identity
Total Output = Intermediate Demand + Final Demand
x = Ax + y → x = (I-A)⁻¹ y
Value Added (Primary Inputs)
Wages, depreciation, EBIT/profit, taxes, imports — not purchased from other sectors.
Price Index Adjustment
To find how price changes propagate:
Ip = (I - Aᵀ)⁻¹ × X̂⁻¹ × (Sum Vector)

🎲 Stochastic Models & Queuing Theory

Binomial Distribution

Formula
P(X=k) = C(n,k) × pᵏ × (1-p)^(n-k)
where C(n,k) = n! / (k!(n-k)!)

Poisson Process

Events occur at constant average rate λ. Arrivals in fixed time → Poisson distribution. Time between arrivals → Exponential distribution.

M/M/1 Queue (Kendall's M/M/s)

Utilization ρ
ρ = λ / μ (must be < 1 for stable queue)
P₀ (no waiting)
P₀ = 1 - ρ
Lq (queue length)
Lq = ρ² / (1 - ρ)
W (time in system)
W = 1 / (μ - λ)
Wq (time in queue)
Wq = ρ / (μ - λ)

🔀 Markov Chains

Markov Property (Memorylessness)
Next state depends ONLY on current state — NOT on the history before it.
Transition Matrix P
P[i][j] = probability of moving from state i to state j. Each row must sum to 1.
State Vector π⁽ᵗ⁾
π⁽ᵗ⁾ = π⁽⁰⁾ × Pᵗ
Trajectory Probability
P(s₀,s₁,s₂) = P(X₀=s₀) × P[s₀→s₁] × P[s₁→s₂]
Absorbing State
Once entered, CANNOT be left: P[i][i] = 1.
Transient State
Once left, there is a positive probability you will NEVER return to it.
Communicating Class
A set of states where every state can reach every other state. Symbol: i ↔ j.
Irreducible Chain
Entire state space is one communicating class (can go from any state to any other).
Stationary Distribution π
Solve: πP = π and Σπᵢ = 1

🔄 System Dynamics & CLD

Positive Link (S = Same)
A →(+)→ B: If A ↑, B ↑. If A ↓, B ↓. Variables move in same direction.
Negative Link (O = Opposite)
A →(-)→ B: If A ↑, B ↓. If A ↓, B ↑. Variables move in opposite directions.
Reinforcing Loop (R / +)
Amplifies change → exponential growth or decay.
Rule: EVEN number of negative (o) links. R
Balancing Loop (B / -)
Seeks equilibrium, opposes change, goal-seeking.
Rule: ODD number of negative (o) links. B
Delay
Time lag between cause and effect. Indicated by a double line (‖) crossing the arrow.
Counting loop polarity: Count the number of O (negative/opposite) links in a loop.
Even count → Reinforcing  |  Odd count → Balancing

🖥️ Simulation Types

Computer Simulation
Imitation of real-world system processes over time. Used when analytical models are mathematically impossible or too complex.
Discrete Event Simulation (DES)
Variables change state only at discrete points in time (events). Example: customer arrivals at a bank.
Continuous Simulation
States change continuously over time. Example: fluid through a pipeline, System Dynamics models.
Monte Carlo Simulation
Uses repeated random sampling from probability distributions to model uncertainty and calculate output distributions.
Agent-Based Simulation (ABS)
Models individual autonomous decision-making agents that interact, producing emergent system-level behavior.
🔄 System Archetypes (CLD Structures)

Click any archetype card to expand the full Causal Loop Diagram structure with link polarities and loop types. These match the exact course slides tested in Part 1.

🌱
1. Limits to Growth
R + B loops
▶
R1: Efforts →(s)→ Performance →(s)→ Efforts
Performance →(s)→ Limiting Action
Constraint →(s)→ Limiting Action
Limiting Action →(o)→ Performance [B2]
Message: Push harder before the constraint kicks in. Or relax the constraint.
🐟
2. Tragedy of the Commons
R+R + B+B loops (figure-8)
▶
R1: A's Activity →(s)→ Net Gains for A →(s)→ A's Activity
R2: B's Activity →(s)→ Net Gains for B →(s)→ B's Activity
A's Activity →(s)→ Total Activity
B's Activity →(s)→ Total Activity
Total Activity →(o, ‖delay)→ Gain per Individual
Gain per Individual →(s)→ Net Gains for A & B
B5: A's Activity → ... → Net Gains A → A's Activity (Balancing)
B6: B's Activity → ... → Net Gains B → B's Activity (Balancing)
Message: Regulate the commons. Individual greed destroys collective welfare.
💊
3. Shifting the Burden
B+B+R loops
▶
Problem Symptom →(s)→ External Intervention
External Intervention →(o)→ Problem Symptom [B1]
Problem Symptom →(s)→ Internal Solution
Internal Solution →(o, ‖delay)→ Problem Symptom [B2]
External Intervention →(s)→ Dependence
Dependence →(o, ‖delay)→ Internal Solution
R3: External Intervention→Dependence→Internal Solution→Problem→External Intervention
Message: The "quick fix" creates dependency. Invest in the internal solution.
⚔️
4. Escalation
B+B → Creates R loop
▶
B1: Activity A →(s)→ A's Result →(s)→ Quality of A's Position →(o)→ Threat to A →(s)→ Activity A

B2: Activity B →(s)→ B's Result →(o)→ Quality of A's Position →(s)→ Threat to B →(s)→ Activity B

B1 + B2 together form a Reinforcing figure-8 of competitive escalation.
Message: One side must unilaterally de-escalate, or agree on mutual limits.
🔧
5. Fixes that Fail
B + delayed R
▶
Problem Symptom →(s)→ Fix
Fix →(o)→ Problem Symptom [B1]
Fix →(s, ‖delay)→ Unintended Consequence
Unintended Consequence →(s)→ Problem Symptom [R2]
Message: Anticipate and manage the unintended consequence, or find a fix without side effects.
📉
6. Growth & Underinvestment
R + B + B with delays
▶
R1: Growth Effort →(s)→ Demand →(s)→ Growth Effort
Demand →(o)→ Performance →(s)→ Demand [B2]
Performance →(o)→ Perceived Need to Invest
Performance Standard →(s)→ Perceived Need to Invest
Perceived Need to Invest →(s, ‖)→ Investment in Capacity
Investment →(s, ‖)→ Capacity →(s)→ Performance [B3 with delays]
Message: Invest aggressively in capacity before performance drops. Don't lower standards.
🎯
7. Drifting Goals
B + B loops
▶
B1: Goal →(s)→ Gap →(s)→ Corrective Action →(s, ‖)→ Actual →(o)→ Gap

B2: Goal →(s)→ Gap →(s)→ Pressure to Lower Goal →(o)→ Goal
Message: Maintain the goal. Eroding the goal is not a solution to the performance gap.
🤝
8. Accidental Adversaries
R+R + undercutting
▶
A's success ↔ A's activity [R: A's reinforcing]
B's success ↔ B's activity [R: B's reinforcing]
A's success →(s)→ B's success →(s)→ A's success [R: Partnership]
A's activity →(o, ‖)→ B's success [U: undercutting]
B's activity →(o, ‖)→ A's success [U: undercutting]
Message: Communicate about unintended undercutting effects. Align local optimization with partnership goals.

🦠 Epidemic (SIR) Model — EPIDEMY.mdl

Susceptible ←[infection rate]← Infected ←[infection rate]
Infected →[recovery with imunity]→ Imune population
Infected →[recovery without imunity]→ Susceptible
Infected →[death rate]→ Total deaths

totla number of risk contacts = Susceptible × AVERAGE NUMBER OF RISK CONTACTS
share of infected on the total population = Infected / (Infected + Susceptible + Imune)
infection rate = risk contacts × share infected × INFECTIVITY
exit rate = Infected / AVERAGE DUTATION OF INFECTION
recovery rate = exit rate × (1 - MORTALITY)
recovery with imunity = recovery rate × SHARE OF IMUNE
recovery without imunity = recovery rate × (1 - SHARE OF IMUNE)
death rate = exit rate × MORTALITY

Stock Equations:

Susceptible population = INTEG(recovery without imunity - infection rate, 49990)
Infected population = INTEG(infection rate - recovery without imunity - recovery with imunity - death rate, 10)
Imune population = INTEG(recovery with imunity, 0)
Total deaths = INTEG(death rate, 0)

Constants:

AVERAGE NUMBER OF RISK CONTACTS = 10
AVERAGE DUTATION OF INFECTION = 7 ⚠️ Note the typo "DUTATION" — use exactly this!
INFECTIVITY = 0.05
SHARE OF IMUNE = 0.5
MORTALITY = 0.03
Time: INITIAL=0, FINAL=100 Days, TIME STEP=0.03125
⚠️
The course file spells "DUTATION" (not DURATION) and "Imune" (not Immune). Use these exact spellings if recreating from scratch to avoid marking confusion.

📦 Production & Inventory Control (3 Versions)

Version 1 — Simple Inventory Control

Inventory = INTEG(production - shipment, 4000)
shipment = customer orders
customer orders = 1000 * (1 + STEP(0.1, 10))
average order rate = SMOOTH(customer orders, time period for averaging orders)
desired inventory = average order rate * time period for inventory holdings
desired production = average order rate + inventory correction
inventory correction = (desired inventory - Inventory) / time period for reconciling inventory
production = desired production
Params: averaging=8, holdings=4, reconciling=8

Version 2 — + Workforce Delay

Workforce = INTEG(hire rate - quit rate, 50)
hire rate = quit rate + workforce correction
quit rate = Workforce / time period of average employment
workforce correction = (desired workforce - Workforce) / time period to hire new workers
desired workforce = desired production / average productivity
production rate = Workforce * average productivity
Params: productivity=20, employment=50, hire=24 weeks

Version 3 — + Schedule Pressure (Lookup)

production = production rate * effect of schedule pressure
schedule pressure = desired production / production rate
effect of schedule pressure = table1(schedule pressure)
table1 = ([(0.8,0.8)-(1.2,1.3)],(0.8,0.875),(0.9,0.875),(1,1),(1.1,1.25),(1.2,1.25))

🏛️ Prison Recidivism — Prison.mdl

People in prison = INTEG(repeat offenders - leaving prison, Initial Prisoners)
Ex prisoners = INTEG(leaving prison - repeat offenders, Initial Ex-prisoners)
leaving prison = People in prison / average length of sentence
repeat offenders = Ex prisoners * fractional recidivism rate
fractional recidivism rate = WITH LOOKUP(Prison conditions level, ...)
average length of sentence = 12 Months
ℹ️
