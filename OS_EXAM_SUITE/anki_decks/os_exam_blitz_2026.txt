# ─── MULTITASKING ───
Cooperative vs Pre-emptive multitasking — difference?	Cooperative: apps manage own resources, voluntarily yield CPU. Pre-emptive: OS forcibly manages CPU, can kill misbehaving apps.	exam_multitask
Problem with cooperative multitasking?	A badly written app could crash the entire system by not releasing resources	exam_multitask
Which multitasking do modern OSes use?	Pre-emptive multitasking — OS fully controls resource allocation	exam_multitask
When did OSes adopt pre-emptive multitasking?	Unix: always. Windows: NT/95. Mac: Mac OS X	exam_multitask

# ─── VIRTUAL MEMORY ───
Virtual memory — definition?	OS uses HDD/SSD disk space to simulate additional RAM, allowing programs larger than physical RAM	exam_vmem
Windows vs Linux virtual memory files?	Windows: page files | Linux: swap files	exam_vmem
Recommended swap-to-RAM ratio?	3:1 — swap should be 3 times physical RAM	exam_vmem
Which software manages virtual memory?	The OS kernel — translates virtual addresses into physical addresses	exam_vmem
Swapping vs Paging — difference?	Swapping: moves entire process to disk. Paging: moves fixed-size blocks (pages) between RAM and disk.	exam_vmem
What is FIFO page replacement?	Replace the page that has been in memory the longest. Suffers from Belady's Anomaly.	exam_vmem
What is LRU page replacement?	Replace the Least Recently Used page. No Belady's Anomaly. More efficient than FIFO.	exam_vmem
What is Belady's Anomaly?	Counter-intuitive: adding more frames causes MORE page faults in FIFO. Doesn't occur in LRU.	exam_vmem

How do private IPs reach the internet?	NAT — Network Address Translation — converts private IP to public IP at the router	exam_net
DNS — what kind of system?	Distributed database resolving domain names to IP addresses. Reads domain from right to left.	exam_net
SSH vs plain terminal — difference?	SSH uses encrypted channel on port 22. Plain terminal/Telnet is unencrypted.	exam_net
Default diagnostic tools in Windows AND Linux?	ping and traceroute (tracert on Windows)	exam_net
What does ping do?	Sends ICMP Echo Request to test connectivity and measure round-trip time	exam_net
What does traceroute do?	Traces path packets take to destination using TTL. Linux: traceroute, Windows: tracert	exam_net

# ─── PROTOCOLS ───
TCP vs UDP — key difference?	TCP: connection-oriented, reliable, ordered. UDP: connectionless, no guarantee, faster.	exam_protocols

DHCP DORA process?	Discover → Offer → Request → Acknowledge	exam_protocols
Port numbers — HTTP, HTTPS, SSH, FTP, DNS, SMTP?	HTTP=80, HTTPS=443, SSH=22, FTP=21, DNS=53, SMTP=25	exam_protocols

CoAP — what transport? What model?	Runs over UDP. RESTful request/response (GET/POST). For lightweight IoT nodes.	exam_protocols
