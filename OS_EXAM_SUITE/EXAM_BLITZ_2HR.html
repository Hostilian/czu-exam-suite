OS Core Facts
OS controls: CPU time + Operating memory (RAM)
NOT an OS function: Defragmentation (it's a disk tool)
OS built with: C, C++, C#, Assembly language
Linux: Open-source OS kernel by Linus Torvalds, 1991
BIOS: Stored in EEPROM or NAND flash memory on motherboard
FAT16 max: 4 GB (16-bit cluster addressing limit)
💾
Virtual Memory
Definition: OS uses HDD/SSD disk space to simulate extra RAM
Windows: page files | Linux: swap files
Recommended ratio: 3:1 (swap space : RAM)
Managed by: The OS kernel — not hardware
Swapping: Moving entire process to disk
Paging: Moving fixed-size blocks (pages) between RAM and disk
⚡
Multitasking Types
Cooperative
Pre-emptive ✓ Modern
Apps manage own resources. Voluntarily yield CPU. Bad app = system crash.
OS forcibly manages CPU. Can kill misbehaving apps. All modern OSes.
Adoption: Unix = always had it. Windows = NT/95. Mac = Mac OS X.

Complete exam-oriented coverage of Operating Systems topics

What Makes an OS?
5 KEY COMPONENTS
Kernel — links apps to hardware
File System — data storage on LTSD
Programming Language — C, C++, Assembly
User Interface — GUI or CLI
API — communication between programs
2 MAIN PURPOSES
Resource management: CPU time + RAM
Bridge: between user/apps and hardware
WHAT OS DOES NOT DO
Defragmentation is done by a utility tool, NOT the OS itself!
COMPUTING MODELS
Batch processing: Jobs queued, no user interaction, mainframe runs them one-by-one
Host-terminal: Central mainframe, dumb terminals carry only I/O
PC model: Each user gets own CPU, RAM, local storage
💾
Virtual Memory Deep Dive
OS uses HDD/SSD to extend available RAM beyond physical limit
Divided into page files (Windows) or swap files (Linux)
Process: inactive pages moved to disk; needed pages loaded to RAM
Managed by: OS kernel — translates virtual → physical addresses
Swapping: entire process → disk
Paging: fixed-size blocks (pages) moved between RAM ↔ disk
Recommended ratio: 3:1 — swap space should be 3× the physical RAM
Exam question: "Which software manages virtual memory?" → The OS kernel
🔄
Deadlock Conditions
ALL FOUR must hold simultaneously for deadlock to occur
1. Mutual Exclusion — resource can only be used by one process at a time
2. Hold and Wait — process holds resource AND waits for more
3. No Preemption — resource can't be forcibly taken from a process
4. Circular Wait — chain of processes each waiting for the next
Deadlock Handling:
Prevention: Eliminate one of the 4 conditions
Avoidance: Banker's Algorithm — safe state analysis
Detection + Recovery: Allow deadlock, detect, then recover

⚙️
CPU Scheduling Algorithms
FCFS: First Come First Served — simplest, can cause convoy effect (long job blocks all)
SJF: Shortest Job First — optimal avg waiting time, but can starve long processes
Round Robin: Each process gets quantum Q time slice. Fair. Context switch overhead.
Priority: Highest priority runs first. Risk of starvation → solved by Aging
Formulas: Waiting Time = Start − Arrival | Turnaround = Finish − Arrival

What is a Server?
A server is a role a device takes to provide services to end users — NOT necessarily a physical machine
Typically assigned to powerful mainframes due to high request volume and OS/hardware limits
Capable of running many calculations; outputs stored on dedicated storage arrays
Common misconception: "a server is a powerful dedicated computer" — actually it's just a role!

Subnetting Cheat Sheet
Network Address: IP AND Mask (all host bits = 0)
Broadcast: network + all host bits = 1
Usable Hosts: 2^(host bits) − 2
First Host: network address + 1
Last Host: broadcast − 1
Private IP Ranges:
Class A 10.0.0.0/8
Class B 172.16.0.0/12
Class C 192.168.0.0/16
Powers of 2 Reference:

2⁶=64
2⁵=32
2⁴=16
2³=8
2²=4
2¹=2
Example: 192.168.10.0/24 → Mask: 255.255.255.0 | Hosts: 2²⁴⁻²⁴... wait: 2⁸−2 = 254 hosts

Network Devices by Layer
1Hub — broadcasts to all ports, no intelligence
2Switch — uses MAC addresses, sends to specific port
3Router — IP addressing, connects different networks
3+Firewall — packet filtering, stateful inspection
ARP: Address Resolution Protocol — maps IP → MAC address
NAT: Network Address Translation — private → public IP at router
Default Gateway: Router IP that handles traffic leaving local network

chmod Permission Numbers
7 = rwx (4+2+1)
