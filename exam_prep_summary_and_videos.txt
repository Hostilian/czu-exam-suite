PART 1: OPERATING SYSTEMS & COMPUTER NETWORKS (OS)
--------------------------------------------------------------------------------
EXAM ANALYSIS & CORE QUESTIONS TO PASS:
1. CPU Scheduling Calculations:
   - You will be given a set of processes with arrival times and burst times. You
     must calculate average waiting time or draw a Gantt Chart.
   - Algorithms: FCFS (non-preemptive, suffers from convoy effect), SJF 
     (optimal waiting time, but can cause starvation), Round Robin 
     (preemptive, relies on a time quantum Q).
2. Network Interface Configuration (Subnetting):
   - Configuring an interface requires: IP Address (uniquely identifies node),
     Subnet Mask (defines local network boundary), Default Gateway (for external
     routing), and DNS (resolves names to IPs).
   - DHCP DORA Process: Discover (broadcast), Offer (server response), Request
     (client selects), Acknowledge (server confirms lease).
3. Memory Management:
   - Virtual Memory: Moves inactive ('cold') pages from RAM to secondary storage
     (swap space) to prevent crash errors. Maintained by the OS kernel.
   - Swapping (moves entire process) vs Paging (moves fixed-size pages).
4. Storage & File Systems:
   - FAT16 Volume limit: 4 GB max volume size (limited by 16-bit addressing of 
     clusters). 
   - Defragmentation: A utility tool, NOT a core kernel function.
5. Autonomous Agent Batch Malware:
   - Malicious software in autonomous agent batch model is called a Botnet.

PART 2: MARKUP LANGUAGES (XML, JSON, HTML)
--------------------------------------------------------------------------------
EXAM ANALYSIS & CORE QUESTIONS TO PASS:
1. HTML5 Semantics:
   - Semantic tags carry meaning: <header>, <nav> (navigation), <main>, <article>
     (standalone/reusable piece), <section> (thematic grouping), <aside> 
     (sidebar/tangential content), <footer>.
   - Allowed in <head>: <title>, <meta>, <link>, <style>, <script>.
2. XML Structure & Schemas (DTD/XSD):
   - Well-formed XML: Basic syntax rules (1 root, closed tags, case-sensitive,
     quoted attributes).
   - Valid XML: Well-formed AND conforms to a DTD or XML Schema (XSD).
   - XML Schema custom types: defined using <xs:simpleType> (for restrictions/facets)
     and <xs:complexType> (for elements with attributes or nested child elements).
   - XML Schema restrictions (facets): xs:enumeration (fixed list), xs:minInclusive
     / xs:maxInclusive (numerical bounds), xs:pattern (regular expressions).
3. JSON & JSON Schema Validation:
   - JSON native data types: string, number, object, array, boolean, null. (Note:
     date and float are NOT native JSON types!).
   - JSON Schema constraints: minLength/maxLength (string length limits),
     uniqueItems: true (no duplicate values in arrays), properties/required.
4. XPath Navigation:
   - Absolute path (starts from root `/`) vs Relative path (anywhere using `//`).
   - Selecting attributes: uses the `@` symbol (e.g. `//@id`).
5. Web Protocols & APIs:
   - HTTP safe methods: GET is safe (read-only); POST, PUT, DELETE manipulate data.
   - HTTP status codes: 2XX (success), 5XX (server error).
   - WebSockets: Persistent, bidirectional, full-duplex connection (unlike HTTP).

PART 3: INFORMATION SYSTEMS (IS)
--------------------------------------------------------------------------------
EXAM ANALYSIS & CORE QUESTIONS TO PASS:
1. Systems Theory Basics:
   - Philosophy (seeks general truths with universal validity) vs Science (seeks 
     practical models/theories that describe reality for practical benefits).
   - Data (unprocessed/unorganized representation of facts) vs Information (useful
     data; key properties are Accuracy and Relevance).
2. Systems Evolution:
   - 1970s Systems: Batch processing, separate applications, routine task efficiency.
   - Modern Systems: Distributed processing, 24/7 connection, strategic change & innovation.
   - Transaction Processing System (TPS): Oldest category of IS in history (operational).
   - Decision Support System (DSS): Newest tech category (strategic predictions).
3. Databases vs Data Warehouses:
   - DBMS functions: Independent database applications and multi-app data sharing.
   - Data Warehouse: Subject-oriented, integrated, non-volatile, time-variant database
     optimized for analytical query processing (OLAP), not daily transactions (TPS/OLTP).
   - ERP: Standardizes business processes and centralizes data. Disadvantages include
     high implementation costs and vendor lock-in.
   - SAP S/4 HANA: Next-gen ERP using in-memory computing (processes in RAM for speed).
4. Decision Making & Security:
   - Decision Types: Structured (fully specified procedures, e.g. payroll), Semi-structured
     (some parts predefined), Unstructured (human judgment, intuition).
   - BPM (Business Performance Management): BI + Planning, using KPIs to monitor.
   - Competitive Intelligence (CI): Legal/ethical gathering of public info (press releases).
   - Cloud Computing: SaaS (Software), PaaS (Platform), IaaS (Infrastructure).

PART 4: OPERATIONS RESEARCH & SYSTEMS ANALYSIS (ORSA)
--------------------------------------------------------------------------------
EXAM ANALYSIS & CORE QUESTIONS TO PASS:
1. System Dynamics Vensim Rules (Crucial!):
   - Stock-to-Stock direct connection is NEVER ALLOWED (violating this results in a
     -10 points deduction!). A stock must only connect to another stock through a 
     Flow rate (valve).
   - Stock equations must use `INTEG(Inflows - Outflows, Initial Value)`.
   - Causal loop polarity: even count of negative/opposite links is Reinforcing (R);
     odd count of negative links is Balancing (B).
   - System Archetypes: Limits to Growth (R growth vs B constraint), Tragedy of the
     Commons (Shared resource depletion), Shifting the Burden (Quick fix dependence),
     Fixes that Fail (Quick fix leads to delayed reinforcing worsening).
2. Queueing Theory (M/M/1):
   - Utilization ρ = λ / μ (Must be < 1).
   - Idle probability P₀ = 1 - ρ.
   - Average queue length Lq = ρ² / (1 - ρ).
   - Average time in queue Wq = ρ / (μ - λ).
3. Leontief Input-Output Analysis:
   - Coefficient Matrix A: Divide each column cell by that column's Total Input.
   - Identity Matrix I: Diagonal 1s, others 0s.
   - Core equation: x = (I - A)⁻¹ * y (y = final demand, x = total output).
4. Markov Chains:
   - Memoryless property: Next state depends ONLY on the current state.
   - State transition: π⁽ᵗ⁾ = π⁽⁰⁾ * Pᵗ.
   - Stationary distribution solve: π * P = π, with Σπ = 1.
5. Linear Programming & Simplex:
   - Excel Solver: LHS formulas must use `=SUMPRODUCT(variables, coefficients)`.
   - Sensitivity Analysis: Simplex basis remains same if changes to RHS or objective
     coefficients are within their allowable increase/decrease intervals.
